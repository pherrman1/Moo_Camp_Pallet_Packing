\begin{abstract}
This document gives an abstract mixed-integer linear programming (MILP)
formulation for the discrete pallet-packing model developed in the project.
The formulation describes the mathematical structure of the model rather than
the instance-specific expansion generated by an optimizer.  Candidate box
placements are enumerated before optimization; the MILP then chooses exactly
one candidate placement for each item while enforcing pallet capacity,
non-overlap, support, compatibility, accessibility, and symmetry conditions.
Several linear objectives can be optimized sequentially to obtain a Pareto
front between compactness, accessibility, and vertical center-of-mass quality.
\end{abstract}

\section{Modeling approach}

The physical dimensions are discretized using a grid of size $g$ millimetres.
For each item, allowable orientations and feasible grid coordinates are
enumerated in a preprocessing step.  A \emph{placement} is therefore a fully
specified choice of item, pallet, orientation, and three-dimensional position.
The MILP does not search over continuous coordinates: it selects from this
finite placement set.

This position-indexed construction has two useful consequences.  First,
geometric coefficients such as overlap areas and occupied cells are constants
known before optimization.  Second, non-overlap and support can be expressed
with linear inequalities over binary placement variables.

\section{Primitive sets, indices, and input data}

All dimensions used by the MILP are integer numbers of grid cells.  The grid
size is $g\in\mathbb Z_{>0}$ millimetres; item dimensions are divided by $g$
and rounded upward, while pallet dimensions use the configured nearest-grid
conversion stated below.  The primitive index sets are
\begin{align}
  \Item &:= \{0,\ldots,m-1\},
  &\quad& i,j\in\Item,
  \label{eq:item-set}\\
  \Pallet &:= \{0,\ldots,P^{\max}-1\},
  && p\in\Pallet,
  \label{eq:pallet-set}
\end{align}
where $m\in\mathbb Z_{>0}$ is the number of individual boxes in the input and
$P^{\max}\in\mathbb Z_{>0}$ is the configured number of candidate pallets.
Pallet labels are artificial; a feasible solution may use only a prefix of
$\Pallet$.

Let $L^{\mathrm{mm}},W^{\mathrm{mm}},H^{\mathrm{mm}}\in\mathbb R_{>0}$ be
the physical pallet dimensions.  The implementation assumes they are
compatible with the grid and uses
\begin{equation}
  (L,W,H):=
  \left(\operatorname{round}\frac{L^{\mathrm{mm}}}{g},
        \operatorname{round}\frac{W^{\mathrm{mm}}}{g},
        \operatorname{round}\frac{H^{\mathrm{mm}}}{g}\right)
  \in\mathbb Z_{>0}^3.
  \label{eq:pallet-grid-dimensions}
\end{equation}

For every item $i\in\Item$, the instance and configuration provide the
following constants:
\begin{description}[leftmargin=3.1cm,style=nextline]
  \item[$(\ell_i,w_i^{\mathrm{raw}},h_i)$] Physical length, width, and height
    in millimetres.  The notation $w_i^{\mathrm{raw}}$ distinguishes physical
    width from the item weight defined below.
  \item[$\mathcal O_i$] Finite set of allowed orientation labels for item
    $i$, obtained from the rotation mode and the item's upright-only flag.
  \item[$d_{io}^x,d_{io}^y,d_{io}^z$] Oriented item dimensions in grid cells
    for $o\in\mathcal O_i$.  Specifically, first define
    $\bar d_i=(\lceil\ell_i/g\rceil,\lceil w_i^{\mathrm{raw}}/g\rceil,
    \lceil h_i/g\rceil)$; orientation $o$ applies its configured axis
    permutation to $\bar d_i$ to obtain $(d_{io}^x,d_{io}^y,d_{io}^z)$.
    Each dimension is a positive integer and the input is assumed to satisfy
    $d_{io}^x\le L$, $d_{io}^y\le W$, and $d_{io}^z\le H$.
  \item[$w_i\in\mathbb R_{>0}$] Item weight in kilograms.
  \item[$\rho_i\in\mathbb R_{\ge0}$] Item density in kilograms per cubic
    metre.
  \item[$\Prio_i\in\mathbb Z$] Retrieval-priority value; a smaller value is
    retrieved earlier and therefore has higher retrieval priority.
  \item[$f_i,\chi_i,\varphi_i\in\{0,1\}$] Food, chemical, and fragile flags,
    respectively.  The symbol $\chi_i$ is used for the chemical flag to avoid
    confusion with a grid cell $c$.
  \item[$\kappa_i$] Fixed symmetry key used to identify interchangeable
    copies.  In the implementation it is the tuple consisting of SKU, grid
    dimensions, weight, family, fragile flag, upright-only flag, and retrieval
    priority.
\end{description}
The pallet dimensions are $L,W,H\in\mathbb Z_{>0}$ grid cells.  A solve with
fixed pallet count uses $K\in\{1,\ldots,P^{\max}\}$, and the support fraction
is $\alpha\in[0,1]$ (default $\alpha=0.75$).

\section{Preprocessed sets and fixed mappings}

\subsection{Coordinate and placement sets}

For item $i\in\Item$ in orientation $o\in\mathcal O_i$, the complete
boundary-feasible integer-grid coordinate sets are
\begin{align}
  X_{io}&:=\{0,1,\ldots,L-d_{io}^x\},\\
  Y_{io}&:=\{0,1,\ldots,W-d_{io}^y\},\\
  Z_{io}&:=\{0,1,\ldots,H-d_{io}^z\}.
  \label{eq:coordinate-sets}
\end{align}
Each coordinate is an integer number of grid cells from the pallet origin.
Consequently, these sets contain every grid-aligned position at which the
oriented item remains within the pallet boundaries.  No subset-sum or
normal-pattern restriction is applied.  The complete placement set is
\begin{equation}
  \Place:=\{(i,p,o,x,y,z):i\in\Item,\ p\in\Pallet,\ o\in\mathcal O_i,
             \ x\in X_{io},\ y\in Y_{io},\ z\in Z_{io}\}.
  \label{eq:placement-set}
\end{equation}
Its cardinality is
\begin{equation}
  |\Place|=
  P^{\max}\sum_{i\in\Item}\sum_{o\in\mathcal O_i}
  (L-d_{io}^x+1)(W-d_{io}^y+1)(H-d_{io}^z+1).
  \label{eq:placement-count}
\end{equation}
Therefore, the MILP is exact relative to the chosen physical discretization
$g$: every boundary-feasible grid placement is represented.  This statement
does not claim exactness relative to arbitrary continuous coordinates or undo
the conservative upward rounding of item dimensions.
Thus $q,r\in\Place$ index placements.  Although the mathematical tuple stores
only $(i,p,o,x,y,z)$, the implementation's placement record also stores the
derived oriented dimensions and a unique integer identifier.

For every $q=(i,p,o,x,y,z)\in\Place$, define the fixed projections and derived
geometry
\begin{align}
  i(q)&:=i, & p(q)&:=p, & o(q)&:=o,\\
  \xi_q&:=x, & \eta_q&:=y, & z_q&:=z,\\
  d_q^a&:=d_{i(q)o(q)}^a\quad(a\in\{x,y,z\}),\\
  t_q&:=z_q+d_q^z, & A_q&:=d_q^xd_q^y.
  \label{eq:placement-mappings}
\end{align}
Here $t_q$ is the top coordinate and $A_q$ is the base area in squared grid
units.  The filtered placement sets are
\begin{align}
  \Place_i&:=\{q\in\Place:i(q)=i\} && (i\in\Item),\\
  \Place_p&:=\{q\in\Place:p(q)=p\} && (p\in\Pallet),\\
  \Place_{ip}&:=\Place_i\cap\Place_p && (i\in\Item,\ p\in\Pallet).
  \label{eq:filtered-placement-sets}
\end{align}

\subsection{Occupied cells, footprints, and support sets}

The set of unit grid cells over all candidate pallets is
\begin{equation}
  \Cell:=\{(p,c_x,c_y,c_z)\in\Pallet\times\mathbb Z^3:
  0\le c_x<L,\ 0\le c_y<W,\ 0\le c_z<H\}.
  \label{eq:cell-set}
\end{equation}
For $q\in\Place$, its occupied cells and horizontal footprint cells are
\begin{align}
  \operatorname{Cells}(q):=\{&(p(q),c_x,c_y,c_z)\in\Cell:
  \xi_q\le c_x<\xi_q+d_q^x,\\
  &\eta_q\le c_y<\eta_q+d_q^y,\ z_q\le c_z<t_q\},\\
  F(q):=\{&(c_x,c_y)\in\mathbb Z^2:
  \xi_q\le c_x<\xi_q+d_q^x,\ \eta_q\le c_y<\eta_q+d_q^y\}.
  \label{eq:placement-cells}
\end{align}
For $c\in\Cell$, let
\begin{equation}
  \Place(c):=\{q\in\Place:c\in\operatorname{Cells}(q)\}.
  \label{eq:cell-placement-set}
\end{equation}
For intervals with lower coordinates $a,b$ and lengths $\delta,\gamma$, let
\begin{equation}
  \omega(a,\delta;b,\gamma):=
  \max\{0,\min(a+\delta,b+\gamma)-\max(a,b)\}
  \label{eq:interval-overlap}
\end{equation}
be their overlap length.  The fixed footprint-overlap area of placements
$q,r\in\Place$ is then
\begin{equation}
  A_{qr}:=|F(q)\cap F(r)|
  =\omega(\xi_q,d_q^x;\xi_r,d_r^x)\,
   \omega(\eta_q,d_q^y;\eta_r,d_r^y).
  \label{eq:overlap-area}
\end{equation}
The candidate direct supporters of a raised placement $q$ are
\begin{equation}
  \Support(q):=\{r\in\Place:p(r)=p(q),\ i(r)\ne i(q),\ t_r=z_q,\ A_{qr}>0\}.
  \label{eq:support-set}
\end{equation}
The notation $\Support(q)$ is reserved for support; accessibility relations
use $\mathcal R_{ij}$ below.

\subsection{Column relations for compatibility and accessibility}

Let the horizontal pallet-cell set and the set of internal placement levels be
\begin{align}
  \Cell^{xy}&:=\{(c_x,c_y)\in\mathbb Z^2:0\le c_x<L,\ 0\le c_y<W\},\\
  \mathcal T_p&:=\{\tau\in\{1,\ldots,H-1\}:\tau=z_q\text{ or }\tau=t_q
                    \text{ for some }q\in\Place_p\}.
  \label{eq:column-index-sets}
\end{align}
For $i\in\Item$, $p\in\Pallet$, $c=(c_x,c_y)\in\Cell^{xy}$, and
$\tau\in\mathcal T_p$, define four placement subsets:
\begin{align}
  B^-_{i p c\tau}&:=\{q\in\Place_{ip}:c\in F(q),\ t_q\le\tau\},&
  U^+_{i p c\tau}&:=\{q\in\Place_{ip}:c\in F(q),\ z_q\ge\tau\},\\
  B^=_{i p c\tau}&:=\{q\in\Place_{ip}:c\in F(q),\ t_q=\tau\},&
  U^=_{i p c\tau}&:=\{q\in\Place_{ip}:c\in F(q),\ z_q=\tau\}.
  \label{eq:column-placement-sets}
\end{align}
The superscripts $-$ and $+$ allow a vertical gap; the equality superscripts
describe direct contact at level $\tau$.  Define the valid index tuples
\begin{align}
  \mathcal J^{\mathrm{fc}}:=\{(i,j,p,c,\tau):{}&i,j\in\Item,\ i\ne j,
  \ p\in\Pallet,\ c\in\Cell^{xy},\ \tau\in\mathcal T_p,\notag\\
  &f_i\chi_j+\chi_i f_j\ge1,\ B^-_{i p c\tau}\ne\varnothing,
  \ U^+_{j p c\tau}\ne\varnothing\},\\
  \mathcal J^{\mathrm{frag}}:=\{(i,j,p,c,\tau):{}&i,j\in\Item,\ i\ne j,
  \ p\in\Pallet,\ c\in\Cell^{xy},\ \tau\in\mathcal T_p,\notag\\
  &\varphi_i=1,\ B^=_{i p c\tau}\ne\varnothing,
  \ U^=_{j p c\tau}\ne\varnothing\}.
  \label{eq:hard-relation-indices}
\end{align}
Empty lower--upper pairs are thereby discarded.  The hard relation families
are
\begin{align}
  \mathcal H^{\mathrm{fc}}&:=
  \{(B^-_{i p c\tau},U^+_{j p c\tau}):(i,j,p,c,\tau)\in
  \mathcal J^{\mathrm{fc}}\},\\
  \mathcal H^{\mathrm{frag}}&:=
  \{(B^=_{i p c\tau},U^=_{j p c\tau}):(i,j,p,c,\tau)\in
  \mathcal J^{\mathrm{frag}}\}.
  \label{eq:hard-relation-families}
\end{align}
The active hard-relation set is defined exactly by
\begin{equation}
  \mathcal H:=
  \begin{cases}
    \mathcal H^{\mathrm{fc}}\cup\mathcal H^{\mathrm{frag}},
      &\text{if both rules are enabled},\\
    \mathcal H^{\mathrm{fc}},
      &\text{if only food--chemical separation is enabled},\\
    \mathcal H^{\mathrm{frag}},
      &\text{if only the fragile-support rule is enabled},\\
    \varnothing,&\text{if both rules are disabled}.
  \end{cases}
  \label{eq:active-hard-relations}
\end{equation}

The ordered set of unequal-priority item pairs is
\begin{equation}
  \mathcal A:=\{(i,j)\in\Item\times\Item:\Prio_i<\Prio_j\},
  \label{eq:priority-pair-set}
\end{equation}
where $i$ is the earlier-retrieved item.  For each $(i,j)\in\mathcal A$, the
accessibility-column relations are
\begin{equation}
  \mathcal R_{ij}:=\{(B^-_{i p c\tau},U^+_{j p c\tau}):p\in\Pallet,
  \ c\in\Cell^{xy},\ \tau\in\mathcal T_p,\ B^-_{i p c\tau}\ne\varnothing,
  \ U^+_{j p c\tau}\ne\varnothing\}.
  \label{eq:access-relation-set}
\end{equation}
Thus, a relation $(B,U)\in\mathcal R_{ij}$ represents placements of the
higher-priority item $i$ below placements of the lower-priority item $j$ in a
common vertical column.

\subsection{Identical-item groups and placement ranks}

Let $\mathcal K:=\{\kappa_i:i\in\Item\}$ be the set of distinct symmetry keys.
For $k\in\mathcal K$, define $G_k:=\{i\in\Item:\kappa_i=k\}$ and
\begin{equation}
  \mathcal G:=\{G_k:k\in\mathcal K,\ |G_k|\ge2\}.
  \label{eq:identical-groups}
\end{equation}
Each $\Place_i$ is stored in a fixed deterministic order.  For
$q\in\Place_i$, the constant $r_{iq}\in\{0,\ldots,|\Place_i|-1\}$ is the
zero-based rank of $q$ in that order.  Identical items have equally long,
correspondingly ordered placement lists.

The $a_{ij}$ variables are present only in the soft-accessibility model.  Their

\section{Core feasibility constraints}

\subsection{Exactly one placement per item}

Every item must be placed exactly once:
\begin{equation}
  \sum_{q\in\Place_i}x_q = 1
  \qquad \forall i\in\Item.
  \label{eq:place-once}
\end{equation}

\subsection{Pallet assignment and pallet count}

A selected placement on pallet $p$ activates that pallet.  Conversely, an item
assigned to $p$ may only use $p$ when it is active:
\begin{align}
  \sum_{q\in\Place_p}x_q &\ge y_p && \forall p\in\Pallet, \\
  \sum_{q\in\Place_{ip}}x_q &\le y_p && \forall i\in\Item,\ p\in\Pallet, \\
  \sum_{p\in\Pallet}y_p &= K. &&
  \label{eq:pallet-assignment}
\end{align}

The candidate pallets are symmetry-broken by requiring earlier pallet indices
to be used before later ones:
\begin{equation}
  y_p\ge y_{p+1}
  \qquad \forall p\in\{0,\ldots,P^{\max}-2\}.
  \label{eq:pallet-order}
\end{equation}

\subsection{Stack height and height spread}

If placement $q$ is selected, the height of its pallet reaches at least its
top.  Exactly one selected placement certifies the attained top of each used
pallet:
\begin{align}
  h_{p(q)} &\ge t_q x_q && \forall q\in\Place,\label{eq:height-placement}\\
  u_q &\le x_q && \forall q\in\Place,\label{eq:top-selected}\\
  \sum_{q\in\Place_p}u_q &=y_p && \forall p\in\Pallet,\label{eq:one-top-certificate}\\
  h_{p(q)} &\le t_q+H(1-u_q) && \forall q\in\Place.
  \label{eq:top-attainment}
\end{align}
When $u_q=1$, the last inequality gives $h_{p(q)}\le t_q$, while
\eqref{eq:height-placement} gives $h_{p(q)}\ge t_r$ for every selected
$r\in\Place_{p(q)}$.  Hence the certifying placement is a highest selected
placement and $h_p$ equals its top coordinate.  The certificate is needed:
without it, $h_p$ would only be a lower-bounded envelope and shorter pallet
heights could be inflated artificially to reduce the spread.

An unused pallet has zero height.  The global envelope variables summarize the
used-pallet heights:
\begin{align}
  h_p &\le H y_p && \forall p\in\Pallet,\\
  H^{\max} &\ge h_p && \forall p\in\Pallet,\\
  H^{\min} &\le h_p + H(1-y_p) && \forall p\in\Pallet,\\
  s &= H^{\max}-H^{\min}. &&
  \label{eq:height-spread}
\end{align}
Because $H^{\max}\ge\max_p h_p$ and $H^{\min}$ is no larger than any used
$h_p$, minimizing $s$ makes both envelope inequalities tight.  Consequently,
at a spread-minimizing solution, $H^{\max}=\max_{p:y_p=1}h_p$,
$H^{\min}=\min_{p:y_p=1}h_p$, and $s$ is their difference.

\subsection{Geometric non-overlap}

For every discretized cell, at most one selected placement may occupy that
cell:
\begin{equation}
  \sum_{q\in\Place(c)}x_q\le 1
  \qquad \forall c\in\Cell.
  \label{eq:nonoverlap}
\end{equation}

This cell-clique representation is equivalent to forbidding volumetric overlap
among selected placements, while avoiding a separate binary variable for every
pair of placements.

\subsection{Support of boxes above the floor}

If support constraints are enabled, every selected placement above the floor
must receive at least an $\alpha$ fraction of its base area from placements
directly below it:
\begin{equation}
  \sum_{r\in\Support(q)} A_{qr}x_r
  \ge \alpha A_q x_q
  \qquad \forall q\in\Place:\ z_q>0.
  \label{eq:support}
\end{equation}

The coefficients $A_{qr}$ are known overlap areas, so the constraint is
linear.  Placements with $z_q=0$ require no supporter because they rest on the
pallet floor.

\section{Compatibility and handling constraints}

\subsection{Food--chemical separation}

When food and chemical overlap is prohibited, a food placement and a chemical
placement cannot occupy the same vertical column with one below the other.
The preprocessed set $\mathcal H^{\mathrm{fc}}$ in
\eqref{eq:hard-relation-families} contains every applicable pair $(B,U)$ of
lower and upper placement subsets.  For every active food--chemical relation,
the model imposes
\begin{equation}
  \sum_{q\in B}x_q + \sum_{q\in U}x_q \le 1
  \qquad \forall(B,U)\in\mathcal H\cap\mathcal H^{\mathrm{fc}}.
  \label{eq:food-chemical}
\end{equation}

The same constraint is generated in both vertical directions, so a food item
cannot be above or below a chemical item when their footprints overlap.

\subsection{Fragile items cannot support other items}

For every direct-contact relation with a fragile lower item, the model gives
\begin{equation}
  \sum_{q\in B}x_q
  +\sum_{q\in U}x_q \le 1
  \qquad \forall(B,U)\in\mathcal H\cap\mathcal H^{\mathrm{frag}}.
  \label{eq:fragile}
\end{equation}

Thus a fragile selected placement cannot be a direct supporter of another
selected placement.

\subsection{Symmetry breaking for identical items}

For each $G\in\mathcal G$, sort its item indices increasingly and let
$\operatorname{adj}(G)$ contain the consecutive ordered pairs in that list.
The selected placement ranks of every $(i,j)\in\operatorname{adj}(G)$ are
ordered:
\begin{equation}
  \sum_{q\in\Place_i}r_{iq}x_q
  \le \sum_{q\in\Place_j}r_{jq}x_q
  \qquad \forall G\in\mathcal G,\ (i,j)\in\operatorname{adj}(G).
  \label{eq:symmetry}
\end{equation}

This does not change the set of physically distinguishable packings; it only
removes equivalent permutations of identical boxes.

\section{Accessibility objective and constraints}

For $(i,j)\in\mathcal A$, item $i$ has higher retrieval priority than item $j$
and should not be below $j$ in a common vertical column.  For each relation
$(B,U)\in\mathcal R_{ij}$, the binary violation variable satisfies
\begin{equation}
  a_{ij}\ge
  \sum_{q\in B}x_q + \sum_{q\in U}x_q - 1
  \qquad \forall(i,j)\in\mathcal A,\ (B,U)\in\mathcal R_{ij}.
  \label{eq:access-violation}
\end{equation}

The variable can remain zero when no blocking relation is selected and must be
one if both sides of a forbidden priority relation are selected.  The total
number of accessibility inversions is:
\begin{equation}
  A(a):=\sum_{(i,j)\in\mathcal A}a_{ij}.
  \label{eq:access-objective}
\end{equation}

If accessibility is a hard requirement, $a_{ij}$ is omitted and
$\sum_{q\in B}x_q+\sum_{q\in U}x_q\le1$ is imposed for every
$(i,j)\in\mathcal A$ and $(B,U)\in\mathcal R_{ij}$.  In the default soft
formulation, $A(a)$ is minimized as a secondary objective.

\section{Vertical moment objectives}

The project supports two alternative linear measures of vertical loading.
For a density-weighted objective:
\begin{equation}
  M^{\mathrm{density}}
  =\sum_{q\in\Place}
  \rho_{i(q)}
  \left(\frac{g(z_q+d_q^z/2)}{1000}\right)x_q.
  \label{eq:density-moment}
\end{equation}

For a mass-weighted objective:
\begin{equation}
  M^{\mathrm{mass}}
  =\sum_{q\in\Place}
  w_{i(q)}
  \left(\frac{g(z_q+d_q^z/2)}{1000}\right)x_q.
  \label{eq:mass-moment}
\end{equation}

The factor $z_q+d_q^z/2$ is the vertical center of the selected box in grid
units.  Multiplication by $g$ converts it to millimetres, and division by
$1000$ converts millimetres to metres.  The density or mass coefficient is
fixed data, so both expressions are linear in $x$.

\section{Multi-objective solution strategy}

The implementation solves a sequence of MILPs rather than combining all
objectives into one arbitrary weighted sum.  For each feasible pallet count
$K$, it performs the following lexicographic/Pareto procedure:

\begin{enumerate}[label=\arabic*.]
  \item Minimize the height spread $s$.
  \item Add a constraint fixing $s$ to its optimum and minimize the
    accessibility count $A(a)$.
  \item Retain the best accessibility value as a starting point, then minimize
    the selected vertical moment $M$.
  \item For successive accessibility bounds $\varepsilon$, add
    $A(a)\le\varepsilon$ and minimize $M$ again, where
    $\varepsilon\in\mathbb Z_{\ge0}$ ranges over the configured feasible
    accessibility counts.  The resulting nondominated solutions form the
    reported discrete Pareto front.
\end{enumerate}

Every optimization problem in this sequence has the same binary placement
variables and core feasibility constraints.  Only the objective and the
additional Pareto bound change between stages.

\section{Complete compact MILP}

For reference, the entire soft-accessibility model is collected below.  Let
$\mu_i=\rho_i$ for the density-weighted objective and $\mu_i=w_i$ for the
mass-weighted objective.  The displayed model assumes support is enabled; if
support is disabled, constraint \eqref{model:support} is omitted.  Enabled
hard rules are already represented by $\mathcal H$ in
\eqref{eq:active-hard-relations}.  Define
\begin{align}
  A(a) &:= \sum_{(i,j)\in\mathcal{A}} a_{ij},
  \label{eq:complete-A}\\
  M(x) &:= \sum_{q\in\Place}
  \mu_{i(q)}\frac{g(z_q+d_q^z/2)}{1000}x_q.
  \label{eq:complete-M}
\end{align}
For each fixed pallet count $K$, the abstract multi-objective MILP is

\begin{subequations}
\label{model:complete}
\begin{alignat}{3}
  \underset{x,u,y,h,H^{\max},H^{\min},s,a}{\operatorname{Pareto-minimize}}
  \quad & \bigl(s,\ A(a),\ M(x)\bigr)
  \label{model:objective}\\[0.3em]
  \text{subject to}\quad
  & \sum_{q\in\Place_i}x_q = 1
  && \qquad \forall i\in\Item,
  \label{model:place-once}\\
  & \sum_{q\in\Place_p}x_q \ge y_p
  && \qquad \forall p\in\Pallet,
  \label{model:pallet-nonempty}\\
  & \sum_{q\in\Place_{ip}}x_q \le y_p
  && \qquad \forall i\in\Item,\ p\in\Pallet,
  \label{model:item-pallet-link}\\
  & \sum_{p\in\Pallet}y_p = K,
  &&
  \label{model:exact-pallets}\\
  & y_p \ge y_{p+1}
  && \qquad \forall p\in\{0,\ldots,P^{\max}-2\},
  \label{model:pallet-symmetry}\\
  & h_{p(q)} \ge t_qx_q
  && \qquad \forall q\in\Place,
  \label{model:placement-height}\\
  & u_q\le x_q
  && \qquad \forall q\in\Place,
  \label{model:top-selected}\\
  & \sum_{q\in\Place_p}u_q=y_p
  && \qquad \forall p\in\Pallet,
  \label{model:one-top-certificate}\\
  & h_{p(q)}\le t_q+H(1-u_q)
  && \qquad \forall q\in\Place,
  \label{model:top-attainment}\\
  & h_p \le Hy_p
  && \qquad \forall p\in\Pallet,
  \label{model:unused-height}\\
  & H^{\max}\ge h_p
  && \qquad \forall p\in\Pallet,
  \label{model:max-height}\\
  & H^{\min}\le h_p+H(1-y_p)
  && \qquad \forall p\in\Pallet,
  \label{model:min-height}\\
  & s=H^{\max}-H^{\min},
  &&
  \label{model:spread}\\
  & \sum_{q\in\Place(c)}x_q\le1
  && \qquad \forall c\in\Cell,
  \label{model:cell-clique}\\
  & \sum_{r\in\Support(q)}A_{qr}x_r
      \ge \alpha A_qx_q
  && \qquad \forall q\in\Place:\ z_q>0,
  \label{model:support}\\
  & \sum_{q\in B}x_q+\sum_{q\in U}x_q\le1
  && \qquad \forall(B,U)\in\mathcal{H},
  \label{model:hard-relations}\\
  & a_{ij}\ge
      \sum_{q\in B}x_q+\sum_{q\in U}x_q-1
  && \qquad \substack{\forall(i,j)\in\mathcal{A},\\
                       \forall(B,U)\in\mathcal{R}_{ij}},
  \label{model:access-relations}\\
  & \sum_{q\in\Place_i}r_{iq}x_q
      \le \sum_{q\in\Place_j}r_{jq}x_q
  && \qquad \substack{\forall G\in\mathcal G,\\
                       \forall(i,j)\in\operatorname{adj}(G)},
  \label{model:identical-symmetry}\\[0.2em]
  & x_q\in\{0,1\}
  && \qquad \forall q\in\Place,
  \label{model:x-domain}\\
  & u_q\in\{0,1\}
  && \qquad \forall q\in\Place,
  \label{model:u-domain}\\
  & y_p\in\{0,1\},\quad 0\le h_p\le H
  && \qquad \forall p\in\Pallet,
  \label{model:yh-domain}\\
  & a_{ij}\in\{0,1\}
  && \qquad \forall(i,j)\in\mathcal{A},
  \label{model:a-domain}\\
  & 0\le H^{\min},H^{\max},s\le H.
  &&
  \label{model:height-domains}
\end{alignat}
\end{subequations}

The Pareto objective in \eqref{model:objective} is realized through repeated
scalar MILPs.  The procedure first minimizes
$s$, fixes the optimal spread, and minimizes $A(a)$.  It then solves
$\min M(x)$ under bounds $A(a)\le\varepsilon$ for a sequence of integer
values $\varepsilon$.  The outer loop repeats this process for admissible
values of $K$.  This scalarization enumerates nondominated solutions of the
compact model.

The current solver code already implements the placement, pallet, non-overlap,
support, hard-relation, accessibility, symmetry, and scalarization parts of
this formulation.  Its height model presently omits the top-attainment
variables $u_q$ and constraints \eqref{model:top-selected}--
\eqref{model:top-attainment}.  Those constraints are included here because
they are necessary for the stated meaning ``$h_p$ is the maximum occupied
height'' and for a mathematically valid height-spread objective.  Until the
same constraints are added to the implementation, the code's $h_p$ variables
are only lower-bounded height envelopes and can be inflated.
